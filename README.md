# Cinema OS

Crie o layout completo de um SaaS proprietário chamado "Arte em Cinema OS", sistema interno de gestão operacional da empresa Arte em Cinema.

REFERÊNCIA VISUAL:

Use a imagem de referência fornecida como inspiração visual DIRETA e RIGOROSA para a linguagem da interface: composição, sensação de profundidade, cards arredondados, hierarquia visual, espaçamento, proporções, navegação, gráficos, sobreposição de elementos, estética premium e moderna.

NÃO copie os textos, números, ícones ou conteúdo da referência.

A referência deve servir principalmente como guia de DESIGN SYSTEM e composição.

MUDANÇA FUNDAMENTAL DE CORES:

Substitua completamente os tons azuis da referência por uma paleta sofisticada de CINZA, grafite, preto suave, branco e cinza metálico.

Paleta aproximada:

- fundo: #F4F4F2 / #F7F7F5

- superfícies: branco / #FFFFFF

- cinza claro: #E8E8E5

- cinza médio: #B8B8B3

- grafite: #30302E

- preto suave: #171716

Utilize sombras suaves, transparências discretas, bordas arredondadas e profundidade através de camadas. Evite aparência excessivamente corporativa ou de ERP tradicional.

A interface deve transmitir:

TECNOLOGIA + CINEMA + ENGENHARIA + LUXO DISCRETO + PRECISÃO.

PRINCÍPIO CENTRAL DO PRODUTO

==================================================

O sistema NÃO deve ser apresentado como apenas um CRM.

A venda é o início de um processo operacional.

O fluxo principal deve ser:

LEAD

→ CLIENTE

→ OPORTUNIDADE

→ PROPOSTA

→ VENDA GANHA

→ PROJETO

→ GESTOR

→ ESTOQUE / COMPRAS

→ EQUIPE OPERACIONAL

→ EXECUÇÃO

→ INSTALAÇÃO

→ TESTES

→ ENTREGA

→ PÓS-VENDA

PORÉM:

ESSE FLUXO PRECISA SER TOTALMENTE CONFIGURÁVEL.

Não criar um workflow fixo.

O administrador deve conseguir criar, editar, remover, duplicar e reorganizar etapas.

Exemplo:

[Lead]

→ [Qualificação]

→ [Visita]

→ [Projeto]

→ [Proposta]

→ [Negociação]

→ [Venda]

Mas outro processo poderia ser:

[Lead]

→ [Briefing]

→ [Levantamento]

→ [Proposta]

→ [Aprovação]

→ [Venda]

→ [Instalação]

O sistema deve possuir futuramente um "Construtor de Fluxos", visual e baseado em blocos.

DESIGN SYSTEM

- cantos generosos

- profundidade

- sombras muito suaves

- elementos sobrepostos

- gráficos minimalistas

- tipografia limpa

- números grandes

NÃO criar aparência de sistema financeiro antigo.
